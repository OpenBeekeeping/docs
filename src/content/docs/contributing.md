Open Beekeeping is built in the open, and help is welcome from beekeepers and developers alike.

## Report a problem or suggest an idea

Open an issue on the repository for the tool it’s about:

- [OpenBKA](https://github.com/OpenBeekeeping/openbka/issues)
- [Design system](https://github.com/OpenBeekeeping/design/issues)
- [These docs](https://github.com/OpenBeekeeping/docs/issues)

Say what you were trying to do, what happened, and what you expected.

## Improve these docs

Every page has an **Edit page** link at the bottom, which takes you to its file on GitHub. Each page is a Markdown file in `src/content/docs/`.

When you write:

- Write for a beekeeper first and a developer second.
- Use plain British English and beekeeping’s own words: colony, apiary, super, brood, inspection.
- Be direct and modest: no superlatives, no exclamation marks, no emoji.
- Write Open Beekeeping as two words, and products as one: OpenBKA, OpenApiary.
